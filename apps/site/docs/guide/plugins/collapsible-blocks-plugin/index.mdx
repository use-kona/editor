## Description

Adds a chevron to configured top-level block types. Each configured block starts
a section that ends at the next configured block. Collapsing a section stores
`collapsed: true` on its starting block and hides the intervening blocks.

## Usage

```tsx
import {
  CollapsibleBlocksPlugin,
  HeadingsPlugin,
  KonaEditor,
} from '@use-kona/editor';

const collapsibleBlocksPlugin = new CollapsibleBlocksPlugin([
  HeadingsPlugin.HeadingLevel1,
  HeadingsPlugin.HeadingLevel2,
  HeadingsPlugin.HeadingLevel3,
]);

return <KonaEditor plugins={[new HeadingsPlugin(), collapsibleBlocksPlugin]} />;
```

All configured block types are flat section boundaries: heading levels are not
nested. Sections are expanded when `collapsed` is omitted or `false`.
