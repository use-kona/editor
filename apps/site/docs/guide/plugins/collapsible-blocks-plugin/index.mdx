## Description

Adds a chevron to configured top-level block types. Types are ordered from the
highest to lowest section level. Each configured block starts a section that
ends at the next configured block of the same or higher level. Collapsing a
section stores `collapsed: true` on its starting block and hides every nested
block in that section.

## Usage

```tsx
import {
  CollapsibleBlocksPlugin,
  HeadingsPlugin,
  KonaEditor,
} from '@use-kona/editor';

const collapsibleBlocksPlugin = new CollapsibleBlocksPlugin([
  HeadingsPlugin.HeadingLevel1,
  HeadingsPlugin.HeadingLevel2,
  HeadingsPlugin.HeadingLevel3,
]);

return <KonaEditor plugins={[new HeadingsPlugin(), collapsibleBlocksPlugin]} />;
```

The array order defines hierarchy: an `h1` section includes following `h2` and
`h3` sections until the next `h1`; an `h2` section ends at the next `h1` or
`h2`. Sections are expanded when `collapsed` is omitted or `false`.
